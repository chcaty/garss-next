改动与提交

    1. 复制配置，打开 GitHub 编辑页，替换 sources.json。
    2. 选择新分支并创建 PR，等待地址校验通过后合并。
    3. CI 采集并发布后，网页和手机即可读到更新。

    复制或下载只导出草稿，不代表已提交。页面不保存 GitHub 登录凭据。
