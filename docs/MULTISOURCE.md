# 多源结果页改版

2026-10-29。本次依据用户提供的 `web-monitor` 结果页实现，产品约束见 [PRODUCT](../PRODUCT.md)，界面规范见 [DESIGN](../DESIGN.md)。

## 已实现

- Web 与 Android 首页统一为「全部更新／我的收藏」，按来源分组，提供搜索、来源／分类／类型筛选、只看新增、紧凑视图与收藏撤销。
- 卡片直接打开原文。文章、话题、视频、项目与影视条目分别保留摘要、封面、作者、时长、排名、热度、回复、Star 或评分等实际字段；阅读量与播放量分开命名。
- 手机 Web 使用单行导航、全宽搜索与可展开筛选；桌面显示多列。Android 保留 Material 控件、系统返回与底部导航，宽屏改用侧栏。两端均支持浅色、深色和系统外观。
- 每源先显示六条、每次显示十二个来源，按需展开。失败与零内容来源不进入结果分组；失败来源不进入结果筛选。管理与采集记录仍保留错误，已收藏内容仍可查看。
- 收藏保存内容、类型、指标、分类与来源快照。公共目录变动不会删除本机收藏；原有浏览器收藏 ID 自动补齐仍在目录内的内容。

## 来源覆盖与复用边界

参考项目的 31 个来源全部接入：13 个 RSS 与 18 个非 RSS 适配，逐项见 [来源对照](REFERENCE_SOURCE_MAP.md)。两个敏感内容来源保留解析与配置、默认停用。其他 29 个参考来源完成实际采集验证。

最终本地快照采于北京时间 2026-10-29 23:20：263 个配置源，165 个采集成功、96 个失败、2 个停用；结果页显示 161 个有内容的正常来源、3519 条去重内容、较上次新增 66 条。失败源的历史数据保留但不进入结果页。

`reference_parsers.py` 复用参考项目 `collect.py`、`sources.py` 的解析函数；`board.css` 以参考项目结果页样式为基础，适配拾阅颜色、主题、移动布局与收藏操作。未引入参考项目的定时任务、存储或直接网络层。

采集器统一处理请求、缓存、字节与时间预算、失败重试和来源生命周期。具名适配端点由 `source_adapters.json` 固定，Web 与 Python 共用注册表；Hacker News 的二次请求只允许相应官方条目端点，部分失败不发布残缺榜单。

cnBeta 官方 RSS 与原聚合精选属于不同来源，分别保留并明确命名；开源中国新闻 RSS 与原博客栏目分别保留。阮一峰合并 HTTP／HTTPS 重复配置，沿用原 B001 ID，通过别名兼容临时 ID。

## 数据与发布兼容

v1 路由、manifest、SHA-256 与稳定链接 ID 保留。类型、元数据、逐来源指标、最近成功时间、基线和新增 ID 为可选扩展，旧 RSS 快照仍可读取。

新增与同一来源上次成功目录比较，首次接入与失败不虚报新增。总览以稳定 ID 去重，来源分组保留归属。无发布时间时显示「首次发现」，重复采集不刷新首次时间。榜单成功后使用当前名单，文章流继续保留历史。

来源请求沿用所有者确认、逐源版本哈希、冲突检查、采集和发布流程；OPML 只导出 RSS，JSON 可备份完整配置。本次生成本地预览和验证数据，尚未部署。

- Python：66 项测试、来源配置校验与语法编译通过，覆盖全部适配器、时间与指标、失败基线、历史保留及原有发布流程。
- Web：TypeScript 检查、29 项测试与生产构建通过；浏览器验证来源／类型／新增组合、紧凑视图、收藏与撤销、空结果、手机和桌面布局、深色模式。
- Flutter：静态分析无问题，31 项测试及覆盖率生成通过，debug APK 构建成功；测试包含大字号、宽屏、横屏、收藏离线保留与辅助页面导航。
- 原生界面使用本次任务的只读 Android 模拟器，加载同一份真实校验快照；先验证离线缓存，再恢复联网验证目录与远程图片；GitHub 头像实际显示，豆瓣 CDN 默认请求 418、补齐公开来源请求头后为 200。没有以 Web 截图代替 Android 验证。

App 顶部标题改为「拾阅」，同时压缩重复标题与空筛选高度、统一看点和卡片层级；大字号的看点保持等高，主列表图片失败可随下拉刷新重试。

## 限制

现有其他来源仍可能因超时、失效 RSSHub 路由或服务端限制而失败；结果页隐藏它们，管理与采集记录提供诊断。来源成功数会随网络与上游变化，不等同于配置数量。

本机收藏不跨端同步，原文与远程图片仍依赖网络。Web 未新增离线启动能力。Android 本次交付为调试安装包，真实设备流畅度及正式签名发布仍需独立验证。
